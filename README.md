# Tidepool

Tidepool is a plain HTML, CSS and JavaScript image-search app. In Part 2 you will type a topic, press Search, and see matching pictures in a responsive grid of cards; for now it is the styled interface only. I put the controls in a sticky left panel with the results beside it, so the search box and quick-pick chips stay in reach while you scroll a long grid. I chose a deep sea-teal and amber palette with an automatic light/dark switch, so it looks nothing like a default purple theme and stays readable in any lighting.
